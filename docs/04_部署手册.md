# 部署手册：下载、搭环境、启动

适用于把系统搬到一台新机器（Linux，推荐 Ubuntu 22.04）。全程约 20–30 分钟，其中大部分时间花在等 clone 和装依赖上。

---

## 0 需要准备什么

| 项 | 说明 |
|---|---|
操作系统 | Linux（Ubuntu 20.04/22.04 实测可用） |
Python | **3.10**（3.11+ 可能与 ultralytics/opencv 的 wheel 不匹配） |
磁盘 | 代码 + 权重约 400 MB；数据集另计（OpenEDS 只留 videos 约几百 MB，LPW 约 1.3 GB） |
内存 | 8 GB 起；两个服务同时跑建议 16 GB |
GPU | 可选。NVIDIA 显卡 + CUDA 驱动可提速约 3 倍；无卡时纯 CPU 也能跑 |
网络 | 需要能访问 GitHub（clone）与 PyPI（装依赖） |

---

## 1 下载代码

两个仓库都在同一个 GitHub 组织下，**权重已随仓库提交**，clone 下来就能跑：

```bash
mkdir -p ~/qingque_yolo && cd ~/qingque_yolo

# 轻量版（面向医生，主用）
git clone git@github.com:pupil-recognization-web/pupil-recognition-web-lite.git

# 专业版（训练/科研）
git clone git@github.com:pupil-recognization-web/pupil-recognition-web-pro.git

# 如果只想要其中一个版本，clone 那个即可
```

**没有配置 SSH key 的话**用 HTTPS：

```bash
git clone https://github.com/pupil-recognization-web/pupil-recognition-web-lite.git
```

> **网速提示**：本机实测从 GitHub 拉取约 18 KB/s，105 MB 的轻量版可能要很久。
> 更快的办法：直接拷整个目录（含 `.git`）过去，或先打包 `tar czf code.tar.gz 项目目录` 再传输。
> 拷过去后在项目目录执行 `git remote -v` 确认地址正常即可继续用。

## 2 建 Python 环境

```bash
# 用 conda（推荐）
conda create -n pupil python=3.10 -y
conda activate pupil
pip install -r requirements.txt      # 轻量版：torch 无 GPU 时用 cpu 版
```

`requirements.txt` 的核心依赖：

| 包 | 版本 | 用途 |
|---|---|---|
torch | 2.13+ | 推理/训练 |
ultralytics | **8.4.106** | 分割框架（**版本必须一致**，自定义层是按此版本改的） |
gradio | 6.30.x | 网页界面 |
opencv / numpy / pandas / matplotlib | 见文件 | 图像与绘图 |
mediapipe | 1.2.0 | 面部关键点（专业版 3D 用） |

> **ultralytics 的版本是关键**。项目依赖被改过的 ultralytics（新增 BiFPN_Concat / StripConv 等层），
> 若装的是别的版本，权重会加载失败并报 `unknown layer`。遇到时用 `patches/ultralytics_custom/apply.sh` 覆盖。

## 3 准备数据（可选）

系统需要两个数据集目录，只做推理的话**只要 videos 这一层**：

```bash
# 默认期望的位置
~/qingque_yolo/openEDS/openEDS/videos/*.mp4
~/qingque_yolo/LPW/videos/*.mp4
```

放在别处也行，用环境变量指过去（推荐写进 `~/.bashrc`）：

```bash
export PUPIL_OPENEDS_DIR=/data/openEDS/openEDS/videos
export PUPIL_LPW_DIR=/data/LPW/videos
```

数据集本身不进 git（12 GB 级），从原机器拷或从官方渠道下载。

## 4 启动

**轻量版（端口 8081）**

```bash
cd ~/qingque_yolo/pupil_recognition_web_lite
./start.sh
# 打开 http://<本机IP>:8081
```

**专业版（端口 8080）**

```bash
cd ~/qingque_yolo/pupil_recognition_web_v2
./start.sh
# 打开 http://<本机IP>:8080
```

停止：

```bash
./stop.sh              # 按端口释放，不依赖 PID 文件
```

日志：

```bash
tail -f app.log        # 运行日志（超过 5 MB 自动滚动为 app.log.1）
```

## 5 第一次运行：自检

```bash
cd ~/qingque_yolo/pupil_recognition_web_lite
python tools/selfcheck.py      # 依赖 / 模型 / 目录 / 一条 CSV 的报告链路
python tools/smoke_test.py     # 30 项全链路断言（含数值基线）
```

两项都应打印 `FAIL 0` / `30/30 项通过`。专业版同理（27 项）。

如果 selftest 报"模型权重不存在"，检查：

```bash
ls models/*/model.pt models/*/plr_model.pt
```

## 6 开机自启（可选但强烈建议）

仓库里带了 systemd 单元和安装脚本：

```bash
sudo bash /home/qingque/qingque_yolo/install_service.sh
```

它会：停掉手工起的进程 → 复制两个 unit → `enable --now` → 打印状态。
单元里已配 `Restart=always`（进程挂了 5 秒后自动拉起）和内存上限（避免把整机拖垮）。

卸载：

```bash
sudo bash /home/qingque/qingque_yolo/install_service.sh --uninstall
```

## 7 可选：GPU 加速

有 NVIDIA 卡时，程序自动用 GPU（`ultralytics` 默认 auto）。也可显式控制：

```bash
PUPIL_YOLO_DEVICE=cpu ./start.sh     # 强制 CPU（GPU 被其他任务占满时）
PUPIL_YOLO_DEVICE=cuda:0 ./start.sh  # 指定卡
```

显存不足 1.2 GB 时程序会自动回退 CPU 并在 `app.log` 记一条，不会崩。

验证 GPU 是否真的在用：

```bash
nvidia-smi --query-gpu=memory.used --format=csv    # 跑一次推理后应上涨几百 MB
```

## 8 日常维护

```bash
./tools/healthcheck.sh            # 端口 / 内存 / 进程 RSS / 日志 / 最近错误
./tools/check.sh                  # 体检 + 冒烟
./tools/backup.sh                 # 备份患者历史、标定、代码快照（默认 /mnt/backup/pupil_backups）
```

建议加进 crontab：

```bash
0 23 * * * ~/qingque_yolo/pupil_recognition_web_lite/tools/backup.sh >/dev/null 2>&1
```

### 升级代码

```bash
cd ~/qingque_yolo/pupil_recognition_web_lite
git pull
./stop.sh && ./start.sh
python tools/smoke_test.py        # 确认没退化
```

### 更新权重

权重已入库，换新权重后：

```bash
git add models/ && git commit -m "更新模型权重" && git push
python tools/make_baseline.py --update    # 若数值变化是预期的，更新基线
```

## 9 常见问题排查

| 现象 | 排查 |
|---|---|
页面打不开 | `ss -ltn \| grep 8081` 看是否监听；`tail -50 app.log` 看启动错误 |
端口被占 | `./stop.sh` 或改 `PUPIL_PORT` |
`ModuleNotFoundError` | 环境没激活或依赖没装：`pip install -r requirements.txt` |
`unknown layer ...` | ultralytics 版本不对，用 `patches/ultralytics_custom/apply.sh` |
模型加载报 shape 不匹配 | 权重与 YAML 不配套，检查 `models/<变体>/*.yaml` |
PDF 导出失败 | 缺 `wkhtmltopdf`：`sudo apt install wkhtmltopdf` |
PDF 中文变方块 | 缺字体：`sudo apt install fonts-noto-cjk` |
识别全失败 | 视频格式/编码问题，先用 `ffmpeg -i input.mp4` 确认可解码；必要时转码 `-c:v libx264` |
推理极慢 | 没吃到 GPU：检查 `nvidia-smi`，或显存不足已自动回退 CPU（看日志） |
服务隔一阵就消失 | 被 OOM Kill。装 systemd（自动重启）或先停一个服务；`free -h` 确认内存 |
clone 很慢 | 网络限速，直接拷目录比 clone 快 |
