# 瞳孔识别平台 · 专业版使用报告

**版本**：v1.0.0　**适用对象**：算法/工程人员、科研使用、数据集与模型维护　**形态**：浏览器网页（`http://<IP>:8080`）

---

## 一、与轻量版的定位差异

| | 轻量版（8081） | 专业版（8080） |
|---|---|---|
目标用户 | 临床医生、护士 | 算法/科研人员 |
核心流程 | 三步：选录像 → 标定 → 结果 | 训练 → 推理 → 分析 → 报告，全链路可控 |
可调参数 | 极少（患者上下文） | 模型、阈值、去模糊、光流、ROI、3D 全部可调 |
训练 | 不支持 | 支持（网页内发起/停止/看日志） |
去模糊 | 不支持 | 支持（11 个专家网络） |
3D 注视 | 不支持 | 支持（VOGeo-Gaze） |
报告 | 面向医生的 PDF | 多页技术 PDF（含曲线、逐帧、关键帧、双眼对比） |

两个版本**共用同一套分割权重与 PLR 算法**，所以同一段录像在两个版本里得到的数值一致（轻量版冒烟测试正是这样校验的）。

## 二、功能地图

### 2.1 瞳孔分割推理

| 子页 | 用途 |
|---|---|
**图片推理** | 单张图片分割，看掩码叠加与椭圆拟合效果 |
**视频推理** | 逐帧分割 + 视频输出 + 逐帧 CSV（PLR 参数计算的基础） |
**数据集测试** | 批量跑数据集里的视频，统计检出率与失败样本 |

关键可调项：模型变体（baseline / mac / strip）、是否用 PLR 专用权重、置信度、IOU、最大帧数、是否光流补帧。

### 2.2 瞳孔分割训练

- 选择模型 YAML、数据集 YAML、轮数、batch、imgsz、lr0、设备；
- 一键「开始训练」，实时刷新日志；
- 支持「继续训练（resume）」与「从头训练（删检查点）」；
- 训练输出目录与手动训练隔离（`*_web` 后缀），不会覆盖既有权重。

> 训练脚本封装在 `scripts/yolo_training/train_yolo26_bifpn_loss_v2.py`，网页只是传参调用。

### 2.3 瞳孔运动特征提取

- **运动光流特征提取**：从逐帧 CSV 计算运动统计量（位移、速度、闪烁）；
- **运动光流预定义模型训练**：训练统计量回归模型（Transformer），用于光流特征的归一化；
- **运动光流特征计算**：对已识别视频批量算特征。

### 2.4 瞳孔分割结果分析（单眼 / 双眼）

每个分析页含 6 个折叠面板：

| 面板 | 内容 |
|---|---|
**形态与运动** | 轨迹、直径曲线、速度曲线、检出统计 |
**PLR 参数分析** | 基线/最小值/收缩幅度/速度/潜伏期/NPi + 拟合曲线 |
**3D 动态注视模型** | 调用 VOGeo-Gaze 生成注视方向叠加视频与 gaze.csv |
**临床判读** | 逐条判读结论（直径、反射、MCV、形态、眼位）+ 参考建议 |
**视频与模型概况** | 源视频、模型、帧数、检出率 |
**逐帧数据 + 异常帧** | 前 200 行原始测量值，异常帧单独列出 |

**双眼**页额外给：左右眼对比图、双眼差、分型一致性、合并 PDF。

### 2.5 ROI 裁剪

- **图片 ROI / 视频 ROI**：先粗定位瞳孔区域，再交给分割网络细化（提高小目标稳定性、降低算力）；
- **刺激标定**：在 ROI 页里直接标定光刺激时刻，结果存 `outputs/stimulus_marks/<视频名>.json`，后续所有分析共用。

### 2.6 视频去模糊

- 11 个专家网络（`C0–C4` 轻量版、`C0_v2–C4_v2` 及 `general_v2` 强版）；
- 「立即去模糊」处理单段视频，「刷新修复结果列表」看历史产出；
- GPU 上约 95 ms/帧（600 帧约 1 分钟），CPU 上很慢。

### 2.7 3D 动态注视模型

基于 [VOGeo-Gaze] 的单目 3D 注视估计：输入视频，输出注视方向叠加视频 + `gaze.csv`（逐帧 3D 视线）。

- 结果按 `<CSV 名>` 存到 `outputs/vogeo_results/<stem>/`；
- 分析页的"3D 动态注视模型"面板会自动读取对应目录；
- 实测 20 帧约 1.7 s（GPU/CPU 差异不大，瓶颈在模型启动）。

### 2.8 环境信息

页面底部展示依赖版本、模型清单、路径、GPU 可用性，便于排查"为什么这台机器跑不起来"。

## 二·五、数据从哪来

测试用视频在独立仓库 [`pupil-datasets`](https://github.com/pupil-recognization-web/pupil-datasets)（私有）：

```bash
git clone git@github.com:pupil-recognization-web/pupil-datasets.git
bash pupil-datasets/install.sh ~/qingque_yolo            # 全部 186 段
bash pupil-datasets/install.sh --samples-only ~/qingque_yolo   # 仅 3 段，快速验证
```

装好后视频落在 `~/qingque_yolo/openEDS/openEDS/videos/`，页面「数据集」里选 `OpenEDS` 即可。
原始数据来自 OpenEDS，仅限研究用途，不得公开发布。

## 三、三条典型工作流

### 3.1 科研：从数据到指标

```
数据集测试（批量检出率）
   → 视频推理（生成 CSV）
   → 刺激标定（ROI 页）
   → PLR 参数分析（看曲线是否合理）
   → 导出 CSV / PDF（论文用图与表）
```

要点：先在"数据集测试"里确认模型对这批数据的检出率，再进入正式分析；分析页的"异常帧"面板能快速发现分割崩掉的片段。

### 3.2 工程：重训模型

```
瞳孔分割训练（选 YAML + 数据集 + 轮数）
   → 训练日志观察 loss/mAP
   → 训练完成 → 推理页选新权重验证
   → 通过后替换 models/<变体>/model.pt
   → 跑 tools/smoke_test.py 确认数值基线未退化
```

### 3.3 对比：双眼一致性

```
切到"双眼瞳孔分割结果分析"
   → 左右眼各自选 CSV（或直接上传录像现跑）
   → 双眼差 + 分型一致性
   → 导出合并 PDF
```

## 五、性能参考（本机实测）

| 场景 | CPU | GPU（RTX 5060） |
|---|---|---|
分割单帧 | 66 ms | 13.9 ms |
端到端推理（含编码/CSV） | 293 ms/帧 | 97 ms/帧 |
去模糊 | 慢，不实用 | 95 ms/帧 |
3D 注视 | 9.7 fps | 11.7 fps |
单次分析（含 7 张图） | 约 1.1 s（缓存命中后约 0.1 s） | 同左 |

显存不足 1.2 GB 时推理会自动回退 CPU（避免被其他任务挤爆），日志里有记录。

## 七、边界

- 单眼、单次记录，不适合连续监测（需要视频流接入时改造）；
- 3D 注视为单目估计，绝对角度有误差，趋势比绝对值可靠；
- 去模糊模型在训练分布外的模糊类型上可能失效；
- 判读规则是规则库 + 经验阈值，不是训练出来的分类器，需要临床复核。
